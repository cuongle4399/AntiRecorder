# AntiRecorder - Trình Duyệt PC Bảo Mật & Riêng Tư

AntiRecorder là trình duyệt web riêng tư cao cấp trên **Windows PC**, tích hợp công nghệ chống quay lén màn hình, độ trong suốt nhìn xuyên thấu màn hình và chụp ảnh bảo mật chỉ lưu RAM.

![AntiRecorder Logo](WindowsSecureBrowser/app_icon.ico)

## ⚡ Tính Năng Chính

* **Duyệt Web Nhân Chromium**: Tốc độ cao, hỗ trợ đầy đủ quản lý Tab, Trang yêu thích (Bookmarks), Lịch sử và Đăng nhập Tài khoản Google.
* **Chống Quay Lén Màn Hình (Anti-Screen Recording)**: Cửa sổ trình duyệt tự động tàng hình/đứng hình trước các phần mềm quay phim hoặc chia sẻ màn hình từ xa (OBS, Discord, Zoom, Bandicam...).
* **Độ Trong Suốt Xuyên Thấu (Glass Mode)**: Tùy chỉnh độ trong suốt giao diện từ 20% đến 100% bằng Win32 Alpha Blending để nhìn xuyên thấu hình nền Desktop và các ứng dụng bên dưới.
* **Chụp Ảnh Màn Hình Chỉ Lưu RAM & OCR**: Chụp ảnh khoanh vùng hoặc toàn màn hình lưu hoàn toàn trên RAM (Ctrl+V dán ngay), hỗ trợ tự động quét chữ (OCR) không để lại dấu vết đĩa cứng.
* **Tắt Tiếng Mặc Định (Default Audio Mute)**: Tự động tắt tiếng các trang web để đảm bảo riêng tư tuyệt đối.
