# 🛡️ AntiRecorder - Trình Duyệt Bảo Mật & Riêng Tư

AntiRecorder là trình duyệt web riêng tư cao cấp trên **Windows PC**, tích hợp công nghệ chống quay lén màn hình, tùy chỉnh độ trong suốt nhìn xuyên thấu và hỗ trợ Chrome Extension.

---

## ⚡ Các Chức Năng Chính

* 🥷 **Chống Quay & Chụp Màn Hình (Stealth Mode)**: Tự động tàng hình / hiển thị màn hình đen trước các phần mềm quay phim, chụp ảnh hoặc chia sẻ màn hình (OBS, Discord, Zoom, Bandicam, Teams...).
* 🧩 **Hỗ Trợ Chrome Extension**: Tự động nạp tất cả Extension trong thư mục `Extensions` khi khởi động app và có nút truy cập trực tiếp Chrome Web Store.
* 🌐 **Cấu Hình Proxy Độc Lập Cho Từng Tab**: Hỗ trợ định dạng `ip:port` và `ip:port:user:pass` kèm tính năng test Ping ms Proxy thời gian thực.
* 👁️ **Độ Trong Suốt Xuyên Thấu (Glass Mode)**: Điều chỉnh độ trong suốt giao diện từ 20% đến 100% để nhìn xuyên thấu desktop và ứng dụng bên dưới.
* 📐 **Tự Động Co Giãn Phông Chữ (Responsive DPI)**: Chữ và giao diện tự động phóng to rõ nét khi mở rộng cửa sổ hoặc phóng to màn hình.
* 🔍 **Tùy Chỉnh Scale Web (1% - 300%)**: Mặc định 75%, linh hoạt điều chỉnh dải zoom trang web.
* 📷 **Chụp Ảnh Màn Hình RAM & OCR**: Chụp ảnh màn hình bảo mật chỉ lưu trên bộ nhớ RAM (Ctrl+V dán ngay) + tự động trích xuất chữ OCR.
* ⬇ **Quản Lý Tải Xuống & Bookmarks**: Quản lý file tải xuống (có nút Mở File / Xem Thư Mục trong Explorer) và lưu danh sách trang yêu thích.
* 🔇 **Tắt Tiếng Mặc Định (Audio Mute)**: Tự động tắt tiếng các trang web để đảm bảo riêng tư.
* 🥷 **Ẩn Taskbar & Nút Kéo Di Chuyển**: Ẩn hoàn toàn icon app khỏi thanh Taskbar Windows, kéo di chuyển ứng dụng mượt mà bằng nút `✥`.

---

## ⌨️ Phím Tắt Tiện Dụng

* `F4` hoặc `Ctrl + Shift + Space`: Ẩn / Hiện nhanh trình duyệt.
* `Ctrl + Shift + S`: Chụp ảnh màn hình RAM + OCR.
* `Chuột giữa (Middle-Click)`: Đóng Tab nhanh.
* `Kéo Nút ✥`: Di chuyển cửa sổ ứng dụng.
